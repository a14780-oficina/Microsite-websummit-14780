# Web Summit 2026 – Microsite

## 📌 Sobre o projeto

Este projeto consiste no desenvolvimento de um microsite inspirado no evento **Web Summit 2026**, uma das maiores conferências de tecnologia e inovação do mundo.

O site apresenta informações sobre o evento, o programa, os oradores e as opções de inscrição, através de uma interface moderna e intuitiva.

🌐 **Site online:** https://a14780-oficina.github.io/Microsite-websummit-14780/

## 🎯 Objetivos

- Desenvolver um microsite sobre o Web Summit 2026.
- Aplicar conhecimentos de HTML e CSS.
- Utilizar o Bootstrap para organizar e estruturar os conteúdos.
- Criar uma navegação simples e intuitiva.
- Adaptar o site a diferentes tamanhos de ecrã.

## 📄 Páginas do site

O microsite é composto pelas seguintes páginas:

- **Início (index.html):** Apresentação do evento e informações principais.
- **Programa (programa.html):** Apresentação do programa e horários do evento.
- **Oradores (oradores.html):** Apresentação de alguns dos oradores.
- **Inscrição (contacto.html):** Área dedicada à inscrição e participação no evento.

## 🛠️ Tecnologias utilizadas

- HTML5 – Estrutura das páginas.
- CSS3 – Estilização e personalização do site.
- Bootstrap – Organização dos elementos e criação de layouts responsivos.
- GitHub Pages – Publicação e alojamento do microsite.
